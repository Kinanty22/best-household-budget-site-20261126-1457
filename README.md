HomeLedger — a complete household budget site for the Hartono household: dashboard with spending charts, 80 sample transactions with add/edit/delete, 10 monthly budgets, 4 savings goals, 9 recurring bills, 3-month reports, and CSV export/import. Everything runs locally in the browser with no network requests; data persists in localStorage.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Or open `app/index.html` directly.
